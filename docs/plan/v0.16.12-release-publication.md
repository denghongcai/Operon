# v0.16.12 musl / Alpine and OpenRC Release

Status: In Progress. Phase 141. Not yet published.

Adds native x86_64 and arm64 fully static musl archives alongside existing
GNU/Linux, macOS, Windows and SDK artifacts. Adds Linux OpenRC service
management without replacing systemd user services. No gRPC schema change.
Package and reported protocol versions are aligned to 0.16.12 / v0.16.12.

Source acceptance checkpoints are recorded in `development-phases.md` and
`v0.18.22-musl-alpine-distribution-roadmap.md`. Final release SHA, native ops/s
comparisons, full local/platform CI, exact-SHA pretag gates and draft checksums
must pass before publication. Public downloaded artifacts, native Alpine
runtime/root and non-root FUSE/rebooted OpenRC, install/service/README and
postrelease gates must pass before this phase is marked complete.

Expected public assets: eight Rust archives, SDK archive and SHA256SUMS (ten
total). Alpine 3.22/3.23 are acceptance baselines; ARMv7 musl, apk and Cloudsmith
are excluded. GNU archives remain incompatible with Alpine. musl is not a
universal performance upgrade; report ops/s by workload and retain raw hashes
and timing/RSS auxiliary evidence.
