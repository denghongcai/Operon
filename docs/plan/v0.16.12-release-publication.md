## Public downloaded ops/s comparison

Three alternating-order trials, fresh private state, identical pinned Ubuntu
24.04 runtime per native architecture. Only actual public GNU/musl binaries were
used; binary hashes, integrity assertions and time/RSS auxiliary evidence are
in run `37809763749`. Each table cell is GNU / musl median completed ops/s.

| Workload | x86_64 | arm64 |
| --- | ---: | ---: |
| CLI fs stat | 324.42 / 253.95 | 319.02 / 311.73 |
| CLI complete exec | 195.02 / 154.48 | 197.35 / 184.07 |
| Real FUSE create/read/delete composite | 210.28 / 201.85 | 190.54 / 186.28 |
| CLI ~4 MiB streaming write with integrity | 54.60 / 41.55 | 76.21 / 62.07 |
| CLI ~4 MiB streaming read with integrity | 65.39 / 43.41 | 88.91 / 75.52 |

CLI startup is included; these are not pure RPC throughput measurements. The
public comparison measures shipped flavors with their real toolchains, not
libc as an isolated causal variable. musl regresses on these measured workloads,
especially x86_64 stat/exec/streaming; it is an additional Alpine-compatible
option, not the default GNU replacement or a universal speedup. Absolute time
and RSS are auxiliary only. No parallel-read tuning was performed.
