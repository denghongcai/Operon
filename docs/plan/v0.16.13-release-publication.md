# v0.16.13 Parallel Read Public Release

Status: In Progress. Phase 146 publishes completed source/local Phases 142–145.

Release preparation aligns Rust/SDK/reported protocol versions to 0.16.13 /
v0.16.13 without changing the gRPC schema or the ten-asset GNU/musl/macOS/Windows
contract. Linux still defaults to four FUSE workers; eight is configurable opt-in.
Read concurrency/byte budgets and queue/RPC deadlines are configurable. Daemon
range reads use one blocking task, retaining per-request policy, resolver and
audit plus short-read/Interrupted/EOF correctness.

Pre-version-bump same-toolchain source comparisons are pinned in
`docs/quality/evidence/parallel-read-2026-10-09.json`: opt-in eight-worker
distinct-file four/eight-reader ops/s improve 58%/62% locally and 83%/90% with
20ms client egress delay. Random two-reader local ops/s decreases about 5%.
Absolute values are host-dependent, cache hits are disclosed, no universal
speedup or new consistency/cache guarantee is claimed.
