## Explicit boundaries

External ordinary/lazy unmount detection and in-flight read cancellation are
required. The user accepted disclosure that path-identity checking and the
unmount syscall are not atomic against privileged concurrent overmount.
Do not claim that race is fixed. Buffered I/O signal interruption is not a
universal guarantee; targeted known FUSE requests are separately tested.
Zero configured RPC timeout intentionally permits indefinite network waits,
but owned shutdown must still cancel them. Keepalive is not an RPC deadline.
