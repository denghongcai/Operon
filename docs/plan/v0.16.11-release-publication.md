## Acceptance

- Formatting, strict all-target Clippy and complete workspace tests passed.
- All complete validation groups passed: core 50, runtime 16, SDK 13 and Linux
  system 4. SDK public API/typecheck/build and 23 tests passed; dependency audit
  and current open Dependabot alerts are zero.
- Real TCP/HTTP2 fault tests cover stalled headers, partial unary bodies, upload
  acknowledgements, healthy slow transfers, keepalive-only blackholes with RPC
  deadlines disabled, recovery and no automatic mutation replay. Configured
  deadlines cover ordinary response-body completion; healthy long-lived streams
  retain establishment-only bounds. Every timeout is configurable.
- Actual-daemon 40MiB file/stdin integrity, binary stdout/output/quiet, empty
  uploads and UTF-8-only JSON contracts passed. An injected source error after
  real partial staging cancels with timeout bounds disabled, preserves the old
  target and cleans staging. Windows cancellation tests allow already-started
  blocking operations to finish within a bounded cleanup deadline.
- Workspace root/alias replacement fails closed; containment, permissions,
  staged replacement and native platform regressions passed. Root resolver
  microbenchmarks stayed around 393k–403k ops/s; 10,000-resolution syscall counts
  fell from 100,216 to 70,215. This is not an end-to-end speedup claim.
- Eight nested mount callers completed 160 timer/cancellation cycles without
  per-call OS threads. A 10-record audit page clones exactly 10 of 10,000 events;
  isolated trace caching, borrowed typed persistence, mixed-record restoration,
  corrupted-tail recovery and sticky write failures passed.
- Docker SDK range/8MiB write/bounds/failed replacement/concurrent audit checks,
  deadline-ignoring peer recovery, exec log and audit restart restoration passed.
  All final JSONL lines are valid and full exec bytes survive restart.

## Acceptance corrections and exclusions

The initial green fcb26aa candidate was not tagged: clean measurements exposed
a client adaptive-window regression. Same-daemon controls identified it;
adaptive windows remain configurable but default off. Ordinary deadline and
keepalive defaults remain enabled. Final native/release gates were rerun.

Windows native smoke initially caught an immediate cleanup assertion racing
already-started blocking file work. The test now requires old-target integrity
and complete staging cleanup within five seconds; native Windows acceptance
passed afterward. It does not ignore leaks or retry mutations.

Initial measurements contaminated by concurrent validation load/inherited
Python RSS and runs interrupted by ENOSPC are not counted as final evidence.
CLI RSS now uses GNU time; failed-run logs and recoverably compressed payloads
are retained. Only regenerable scoped Rust debug/incremental caches and a
temporary probe executable were removed to restore disk capacity.
