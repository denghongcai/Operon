# v0.16.8 Security Hardening Release Publication

Status: In Progress.

## Goal

Publish the current v0.16 release line after the post-v0.16.7 security
hardening commit on `main`, then verify public artifacts, install usability,
service-management smoke, and README Quickstart against the published release.

## Version-Line Note

This release packages the latest `main` security hardening into the v0.16
public release line. The earlier v0.18.x maintenance phase names are internal
cleanup batch identifiers, not published artifact versions.

## Plan

1. Align Rust crate versions, TypeScript SDK package version,
   `PROTOCOL_VERSION`, CLI `--version`, release dry-run inputs, and README
   release-maintainer examples to `0.16.8` / `v0.16.8`.
2. Add focused validation for the `v0.16.8` release preparation surface.
3. Run local release-preparation validation.
4. Commit and push the release-preparation changes to `main`.
5. Run main CI and CodeQL on the release commit.
6. Run the manual cross-platform live mount release gates and Windows Runner
   Image Smoke on the release commit.
7. Verify pre-tag gates with
   `scripts/release-gate-orchestrate.sh pretag v0.16.8 <commit>`.
8. Push tag `v0.16.8`, let the Draft Release workflow build artifacts,
   publish the release, and verify public artifacts.
9. Run post-publication `Verify Release Artifacts`, `Verify Release Install
   Usability`, and `Verify README Quickstart` workflows against `v0.16.8`.
10. Verify post-release gates with
    `scripts/release-gate-orchestrate.sh postrelease v0.16.8 <commit>`.
11. Record run IDs, tag, commit, release URL, and remaining limits in this
    phase plan, the phase tracker, and AGENTS.md.
